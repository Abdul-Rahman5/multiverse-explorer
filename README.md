# Multiverse Explorer

A responsive web application for exploring characters from the Rick and Morty universe.

## Live Demo

Coming soon.

## GitHub Repository

This repository contains the complete source code for the project.

## Features

- Character dashboard
- Character search by name
- Filter characters by status
- Filter characters by species
- Pagination
- Character details page
- Episodes for each character
- Responsive design
- Loading skeletons
- Error states
- Empty search results state
- Dynamic status styling

## Tech Stack

- Next.js
- React
- TypeScript
- TanStack React Query
- Tailwind CSS
- classnames
- Rick and Morty REST API
